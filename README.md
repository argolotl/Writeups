# Writeups / Resúmenes de Ejercicios

Este archivo centraliza todos los **writeups** de laboratorios, máquinas virtuales
y retos que he completado durante mi aprendizaje de ciberseguridad y pentesting.

El objetivo de este repositorio de writeups no es solo documentar pasos, sino **reflexionar sobre el proceso**, entender los vectores de ataque y reforzar buenas prácticas de seguridad. Cada writeup incluye:

- 🔹 Descripción del objetivo y alcance del ejercicio  
- 🔹 Metodología utilizada (reconocimiento, enumeración, explotación, post-explotación)  
- 🔹 Herramientas empleadas y por qué se eligieron  
- 🔹 Hallazgos clave y vulnerabilidades identificadas  
- 🔹 Aprendizajes y posibles mejoras de enfoque  

> ⚠ Nota: Todos los writeups están realizados en entornos controlados o laboratorios de práctica. No se incluyen credenciales reales ni información de terceros.

Este repositorio sirve como referencia personal y portafolio profesional para demostrar comprensión de las fases de un pentest completo y la capacidad de documentar hallazgos de manera ética y organizada.
